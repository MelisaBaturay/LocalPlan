# CS101: Summer AI Assistant Lab FAQ

## Grading Policy
The CS101 Summer AI Lab grade is determined by three main components:
- **Phase 1 Foundations (20%)**: Environment setup, running initial local LLM completion, SQLite sandbox exercises.
- **Phase 2 Implementation (50%)**: Building the end-to-end local RAG pipeline, document ingestion, SQLite vector storage, and UI integration.
- **Phase 3 Testing & Final Presentation (30%)**: Project evaluation report, edge-case testing, code quality, and live presentation demo.

## Office Hours & Lab Schedule
- **Instructor Office Hours**: Mondays and Wednesdays from 2:00 PM to 4:00 PM in Lab Room 302.
- **Teaching Assistant (TA) Support**: Tuesdays and Thursdays from 10:00 AM to 12:00 PM online via Discord channel.
- **Lab Hardware Requirements**: Laptops running Windows 11, macOS (Apple Silicon or Intel), or Linux with at least 8GB RAM (16GB recommended). No cloud subscriptions or dedicated GPUs are required.

## Submission Deadlines
- Week 2 Milestone: SQLite database schema and vector embedding sandbox code submission due Friday at 11:59 PM.
- Week 4 Milestone: Fully working offline RAG Chatbot prototype due Friday at 11:59 PM.
- Week 6 Final Presentation: Final code repository, project README, and live demo slide deck due on Demo Day.
